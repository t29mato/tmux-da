## 初版からの変更点

| 変更 | 理由 |
|---|---|
| 折詰（弁当屋・値段つきコース）を**削除**し、からくり屋敷（案B）に差し替え | 「寿司は意識しない」「tmux × 寿司は意味が分からない」。飲食・店・値段のモチーフを全廃 |
| 勇者・モンスター・魔王を**全廃**。閉じる対象は「空き間」「古い記事」「NO SIGNAL」という物に | 「勇者いらない、敵もいらない」。言い換えの敵も置かない |
| ストーリー／練習モード（仕込み・研修・リハーサル）を**削除**。タイトル画面のボタンは「始める」と「記録」の 2 つ | 「タイムアタックだけで十分」。入門は初級コース＋常時キー表示＋手引きで賄う |
| 時間切れで次に進む仕組みを**廃止**。制限時間は「目安」になり、過ぎても解けるまで続く。+5 秒ペナルティ廃止 | 「時間内に終わらないと次に進んでは、いつまでも覚えられない」。ON AIR の「CM に逃げた」も廃止し「押し」に |
| 題名候補を各案 2〜3 本、モック上部と README に掲載。「tmux」を残す | 題名 tmux打 は固定ではなくなった。検索と GitHub のため tmux を残す |
| スピードキューブの文化（PB・Ao5・スクランブル・+2・記法風のキー列）を**全案の枠**として統合 | 世界観としては split/zoom/copy に対応せず、商標の問題もある。記録文化だけなら既存の仕組みに名前を付けるだけで入る |
| 間取り図はからくり屋敷のコース選択「見取り図」に統合。迷い家・千間屋敷は「三間／八間／百間屋敷」のコース名に吸収。無限城の名は不使用 | 独立案にすると案B と区別がつかない。無限城は他作品に寄りすぎる |
| 各モックのプレイ中画面を「目安を過ぎて手引きが出ている状態」で描いた | 新ルールが見た目でわかるように |

寿司打は「ひとつの舞台に、名前からボタンまで全部が乗っている」という**品質の基準**としてだけ参照する。寿司・回転レール・店・値段のモチーフは使わない。比喩は tmux そのもの（分割・移動・全画面・ウィンドウの作成と切替・コピーモード・デタッチ）に対して意味が通ること。

## 全案に共通する前提（ユーザー要件の反映）

| 要件 | 反映 |
|---|---|
| 勇者も敵もいらない | 3 案とも登場人物はプレイヤーだけ。閉じる対象は「空き間」「古い記事」「NO SIGNAL」のような**物**で、敵の言い換えではない |
| 時間切れで次に進まない | **1 問は解けるまで終わらない**。制限時間は「目安」になり、過ぎても飛ばさず、ヒントが段階的に強くなる（下記）。+5 秒の時間切れペナルティは廃止 |
| ストーリーモードは不要 | 3 章 24 面は捨てる。初めての人は、1 問 1 キーの初級コースを「指示を見ながら」解くことで覚える。キーは常に表示、結果画面と記録の間で「遅れた問題」とそのキーが出る |
| 題名は再考 | 各案に題名候補 2〜3 本。検索と GitHub のため **「tmux」を題名に残す**ことを推奨。「〜打」は案C 以外では落とす |

### 「遅れ」の共通ルール（時間切れの代わり）

1. 各問に**目安**（旧・制限時間: 12 / 14 / 18 秒）がある。ゲージは目安まで減り、過ぎたら赤く「超過 +N 秒」と**増えていく**。全体タイムはそのまま走り続ける（遅れそのものが唯一のペナルティ）。
2. 目安を過ぎた瞬間: 押すべきキーが**光って大きくなる**（通常表示の強調）。押し終えたキーは薄くなり、次に押すキーだけが光る。
3. 目安の 1.5 倍を過ぎたら: **1 手ずつの手引き**が出る（「一 合図 Ctrl+b を押して離す ✓ ／ 二 → を押す」）。手引きを見ても追加の秒数ペナルティは無い。
4. 記録には「目安超過 N 問・手引き N 回」が残り、**苦手分析の材料**になる（どのキーで遅れたか）。自己ベストと平均には普通に入る。
5. ミス（違うキー）は従来どおり +2 秒。

この骨格は 3 案で同じで、呼び名と見せ方だけが世界観に合わせて変わる（案A 押しとフロア D、案B 行灯と指南、案C 赤字と先輩）。

### スピードキューブの文化を「枠」として全案に入れたもの

- **PB**（自己ベスト）と **Ao5**（直近 5 回平均。案B・C では「五回平均」）をコース一覧・結果・記録の間に並べる。すでにある「直近 5 回平均」の名前を整えるだけ。
- **同じ問題セットを毎回ちがう順で**（スクランブル）解く、という説明の仕方。
- キーの表示をキューブの手順記法のように横一列に並べ、押したものから薄くなる。
- 違うキーで **+2 秒**（キューブの +2 ペナルティと同じ）。

ルービックキューブそのものを世界観にする案は作らなかった（理由は末尾「採らなかった案」）。

## 案B tmux からくり屋敷 — 襖が立ち、部屋が回る屋敷（concept-2.html）

**題名候補**: **tmux からくり屋敷**（推奨）／ tmux屋敷 ／ からくり tmux

**一言コンセプト**: 「tmux のセッションは、からくり屋敷。襖が勝手に立ち、部屋が回り、壁が開いて大広間になる。指図どおりに仕掛けを解いて、奥の間に辿り着く速さを競う。」

**なぜ噛み合うか**: tmux の操作をすべて「屋敷の仕掛け」として語れる。

| tmux | 仕掛け |
|---|---|
| split（% / "） | 襖を立てて間を仕切る（縦 / 横） |
| focus（矢印） | 隣の間へ渡る |
| zoom（z） | 襖を外して、ひと間を大広間にする |
| close（x） | 間を閉じる（壁を戻す） |
| resize | 襖をずらす |
| swap / layout | 部屋が回る（どんでん返し）／ 田の字に組み替わる |
| new window / select / kill | 離れを建てる ／ 渡り廊下で棟を渡る（母屋・離れ・蔵）／ 棟を閉める |
| rename | 間に名札を掛ける |
| copy mode / search / yank / paste | 掛け軸の裏の巻物を読む（巻き上げる＝スクロール）／ 巻物の文を写して、別の間の扉に書く |
| detach / attach | 屋敷を出ても、仕掛けはそのまま残っている（tmux の本質。タイトルの一言目に置く） |

間取り図の要素（ユーザー案の「間取り図」）は、コース選択の**見取り図**として吸収した。コースが進むほど間数が増える。

### ネーミング一式

- **コース**（見取り図）: **三間屋敷**（15 仕掛け・目安 12 秒）／ **八間屋敷** ★おすすめ（20 仕掛け・14 秒）／ **百間屋敷**（16 仕掛け・18 秒）
- **お題**（指図）:
  1. この間を左右に仕切れ（split）
  2. 掛け軸の間へ渡れ（focus）
  3. 襖を外して大広間にせよ（zoom）／ 襖を戻せ（unzoom）
  4. 空き間を閉じよ（close）
  5. 掛け軸の間を西の端へ回せ（swap）／ 離れを建てよ（new window）／ 母屋に戻れ（select window）／ この棟に camp と名札を掛けよ（rename）／ 棟 trap を閉めよ（kill window）／ 巻物を頭まで巻き戻せ（copy top）
- **称号**（5 段階）: 見習い → 仕掛け番 → 屋敷守 → からくり師 → 名匠
- **結果の決めゼリフ**: 「奥の間に辿り着いた。」→ 目標タイム＝**当主の刻**。「当主の刻 62 秒を **13.8 秒** 上回った」／ 届かなければ「当主の刻まで あと 5.3 秒」。
- **記録の間** → **絵巻**（推移グラフが巻物として横に伸びる）
- **ミス** = 「仕掛け違い +2 秒」／ **遅れ** = 「行灯がともる」（キーが光る）→ **「指南」**（1 手ずつ）／ 絵巻には「灯り N 仕掛け・指南 N 回」／ **連続正解** = 「五連の仕掛け・手際よし」
- 開始 = 「屋敷に入る」、もう一度 = 「もう一度 屋敷へ」、prefix = 「合図」

### UI

- **タイトル**: 夜の藍色。左に「屋敷を出ても、仕掛けはそのまま。」→ 題字「tmux からくり屋敷」（明朝）、口上、合図の切替、「屋敷に入る」（行灯色）「絵巻」。右に和紙の**見取り図**（各コースの間取りミニ図、PB・五回平均・回数）。下端に障子の明かりが並ぶ屋敷の外観。
- **プレイ中**: 左に和紙の**指図**（お題・キー列・ヒント・行灯ゲージ。目安を過ぎると「超過 +3.2 秒」と赤くなり、行灯がともって指南が 1 手ずつ出る）。中央は木枠の**屋敷**（和紙色の端末、襖は二重線、間の名札「茶の間／掛け軸の間／空き間」、いまいる間は行灯の光で暖色に。ステータスバーは藍で「0:母屋* 1:離れ 2:蔵」）。
- **結果**: **絵巻**（両端に軸）。「奥の間に辿り着いた。」→ 秒数 → 当主の刻との差 → 朱印の称号 → 明細（仕掛け違い／灯り／PB／五回平均）→ 直近 10 回の棒。
- **配色**: 夜の藍 #121a2b、和紙 #f3eadb、木 #8a6a3a、行灯の橙 #f0a33a、朱 #b9322a。ライトテーマは昼の屋敷（和紙地に木枠）。
- **フォント**: 明朝（題字・指図・間の名）、ゴシック（注記）、等幅（端末・数字）。
- **音**: 打鍵 = 襖の滑る音、正解 = からくりのカタン、間を渡る = 畳を歩く足音、ミス = 鈴、行灯 = 火の入る音、結果 = 拍子木。

### 初めての人の覚え方

三間屋敷は 1 仕掛け 1 キー。指図にキーが常に出ていて、目安を過ぎれば指南が 1 手ずつ出るので、知らなくても必ず解ける。絵巻の「灯りが多かった仕掛け」が、次に練習するキーを教える。

## 案C tmux 編集局 — 新聞社、締切前（concept-3.html）

**題名候補**: **tmux 編集局**（推奨）／ tmux打 編集局（「打」= 活字を打つ、の意味が残る唯一の案）／ tmux 校了

**一言コンセプト**: 「tmux の画面は組版中のゲラ。ペインは段、ウィンドウは面。デスクの指示どおりに紙面を組み、締切までに校了した速さを競う。」

**なぜ噛み合うか**: 紙面はそもそも段組（split）で、段幅を広げ詰め（resize）、記事を差し替え（swap）、一面トップに全面展開（zoom）し、古い記事はボツ（close）にする。面を増やす・めくる（window）、見出しを付ける（rename）、原稿を頭から読み直す（copy mode）、そして **切り貼り**（copy & paste の語源そのもの）。「締切」はタイムアタックの制限時間として誰にでも通じ、「誤植」「校了」「号外」「縮刷版」と業界語がそのままゲーム用語になる。

### ネーミング一式

- **コース**（締切表）: **夕刊 15 本**（締切 12 秒／本）／ **朝刊 20 本** ★おすすめ（14 秒／本）／ **号外 16 本**（18 秒／本・「特報」判子）
- **お題**（デスクからの指示）:
  1. 紙面を左右二段に割れ（split）
  2. 特ダネの記事へ赤ペンを移せ（focus）
  3. この記事を一面トップに（全面）（zoom）
  4. 古い記事をボツにせよ（close）
  5. 特ダネを左の段へ差し替えよ（swap）／ 新しい面を起こせ（new window）／ 一面に戻れ（select window）／ この面の題字を camp にせよ（rename）／ 面 trap を丸ごとボツに（kill window）／ 原稿の冒頭まで戻れ（copy top）
- **称号**（5 段階）: 新米記者 → 記者 → デスク → 編集長 → 主筆
- **結果の決めゼリフ**: 「朝刊 20 本、校了。」→ **「締切 13.8 秒前に校了」** と **「刷り部数 64 万部」**（目標タイムで 50 万部、速いほど伸びる）。遅れると「締切 5.3 秒超過」。
- **記録の間** → **縮刷版**
- **ミス** = 「誤植 +2 秒」（朱の判子）／ **遅れ** = 「締切延長」（デスクが**赤字**でキーを書き足す）→ **「先輩が横につく」**（1 手ずつ）／ 縮刷版には「延長 N 本・先輩 N 回」／ **連続正解** = 「ノー誤植 ・ 5 本連続」
- 開始 = 「輪転機を回す」、もう一度 = 「次の版を組む」、早見表 = 「用字用語集」

### UI

- **タイトル**: 新聞の一面。題字「tmux 編集局」（編集局は白抜き）、両耳に本日の締切と通算、日付行、2 段組の口上、黒帯の「締切表」、下端に「昨日の見出し／延長が多い指示／号外」の帯。
- **プレイ中**: 暗い机。左に原稿用紙風の指示メモ（クリップ留め、締切ゲージ。締切を過ぎると「延長 +3.2 秒」と赤字が入り、先輩の 1 手ずつが出る）。中央は**ゲラ**（トンボ付きの紙。段の罫は黒、選択中は朱。ステータスバーは黒帯「0:一面* 1:二面」）。
- **結果**: **校了紙**。大きな朱の「校了」判子、秒数、締切 N 秒前、刷り部数、名刺風の称号、明細、直近 10 版の棒。
- **配色**: 紙 #f4efe4、墨 #15120f、朱 #c8261a の 3 色。ダークテーマは机（#2b2622）の上の紙。
- **フォント**: 明朝中心、注記はゴシック、端末は等幅。
- **音**: 打鍵 = タイプライター、正解 = 判子ポン、連続 = 電話のベル、ミス = 赤ペンのキュッ、延長 = 締切のベル、結果 = 輪転機の回り出す音。

### 初めての人の覚え方

夕刊は 1 本 1 キー。指示メモにキーが常にあり、締切を過ぎれば先輩が 1 手ずつ教える。縮刷版の「延長が多い指示」が次の練習対象。

## 案A tmux ON AIR — 放送局の副調整室（concept-1.html）

**題名候補**: **tmux ON AIR**（推奨）／ tmux 生放送 ／ tmux サブ

**一言コンセプト**: 「tmux の画面分割は、副調整室（サブ）のマルチビューそのもの。ディレクターのカンペどおりに画面を割り、カメラをテイクし、生放送を尺どおりに回し切って視聴率を競う。」

**なぜ噛み合うか**: 3 案のうち唯一、比喩ではなく「画面を分割して切り替える」行為そのものが舞台。2 画面に割る（split）、カメラを選ぶ（focus。選択中ペインの枠 = 赤いタリーランプ）、1 カメをフルで送出（zoom）、NO SIGNAL のカメラを落とす（close）、ワイプの大きさ（resize）、ソース入替（swap）、スタジオ A/B を切り替える（window）、VTR を頭まで巻き戻す（copy mode のスクロール = 巻き戻し）。1 問の目安は放送用語の **「尺」**、超過は **「押し」**、目標との差は **「巻き／押し」** と、時間の語彙が最初から揃っている。

### ネーミング一式

- **コース**（番組表）: **深夜枠 15 CUTS**（尺 12 秒／cut）／ **ゴールデン 20 CUTS** ★おすすめ（14 秒／cut）／ **年末特番 16 CUTS**（18 秒／cut）
- **お題**（カンペ。現場の掛け声）:
  1. 画面、左右に割って！（split）
  2. 中継のカメラ、テイク！（focus）
  3. 今のカメラ、フルで！（zoom）／ 2 画面に戻して！（unzoom）
  4. NO SIGNAL のカメラ、落として！（close）
  5. 中継を左のモニターへ！（swap）／ B スタ、立ち上げ！（new window）／ A スタに戻して！（select window）／ スタジオ名を camp に！（rename）／ スタジオ trap、閉局！（kill window）／ VTR、頭まで巻き戻し！（copy top）
- **称号**（5 段階）: AD → フロア D → ディレクター → チーフ D → プロデューサー
- **結果の決めゼリフ**: 「放送終了」→ **「視聴率 25.7%」**（= 20% × 目標タイム ÷ 自分のタイム。目標ちょうどで 20%、40% 超えで「紅白超え」）と **「巻き 13.8 秒」**（目標より速い）／「押し 5.3 秒」（遅い）。
- **記録の間** → **視聴率速報**
- **ミス** = 「放送事故 +2s」／ **遅れ** = 「押し」（尺ゲージが赤く伸びる。カンペのキーが大きくなる）→ **「フロア D が 1 手ずつカンペを出す」**／ 視聴率速報には「押し N CUTS・フロア D N 回」／ **連続正解** = 「NO-CUT ・ 5 連続」
- 開始 = 「本番 5 秒前」（カウントダウンがそのまま「かまえて」）、もう一度 = 「次の本番」、早見表 = 「進行表」

### UI

- **タイトル**: 暗い副調整室。赤く光る ON AIR ランプ、白と赤の「tmux ON AIR」、シアンの一行。右に「番組表」（尺・枠名・PB＋視聴率・Ao5）と 4 分割のモニター壁。
- **プレイ中**: 上帯にタイムコード「00:48.2 ELAPSED」と ON AIR。左に白い**カンペ**（太いゴシック。尺を押すと「押してる！ フロア D が 1 手ずつ出す」が追加される）、その下に LED 風の尺ゲージ（押しは赤いセグメント）。中央は**マルチビュー**（黒の端末、選択中ペインに赤いタリー枠とランプ、NO SIGNAL ペインは砂嵐、ステータスバーはシアン「0:Aスタ* 1:Bスタ」）。
- **結果**: カード。OFF AIR ランプ、視聴率を特大の等幅で、横にタイムと「巻き 13.8 秒」、スタッフパス風の称号、明細（放送事故／押し／PB／Ao5）、直近 10 本の棒。
- **配色**: 黒 #0a0d12、パネル #171d27、赤 #ff2d3a、シアン #37d6e0、アンバー #ffb02e。ライトテーマは「リハーサル中」の明るいサブ。
- **フォント**: 太いゴシックと等幅、英字は大文字トラッキング広め。明朝は使わない。
- **音**: 開始 = 「5 秒前」のビープ、正解 = スイッチャーのカチッ、連続 = タリーのピッ、ミス = 放送事故のブザー、押し = フロアの手拍子（巻きの合図）、結果 = 放送終了のチャイム。

### 初めての人の覚え方

深夜枠は 1 カット 1 キー。カンペにキーが常にあり、尺を押せばフロア D が 1 手ずつ出す。視聴率速報の「押しが多いカット」が次の練習対象。

## 採らなかった案・統合した案

| 案 | 扱い | 理由 |
|---|---|---|
| 折詰（弁当屋）・値段つきコース | **捨てた** | 「寿司は意識しない」「飲食・店・値段は使わない」の要件。tmux と弁当の結びつきも弱かった |
| 無限城 | 名前は使わず、**からくり屋敷**（案B）に | 他作品の固有名に寄りすぎる。「部屋が組み替わる屋敷」の発想はからくり屋敷で全部受けられる |
| 迷い家・千間屋敷・百間御殿 | **コース名に吸収** | 「三間 → 八間 → 百間」の数字遊びとして残した。迷い家は「迷う」が主眼で、仕掛けを解く能動性に欠ける |
| 間取り図（大工・建築士） | **案B に統合** | コース選択の「見取り図」と、襖を立てる＝壁を引く、の部分がそのまま屋敷に乗る。独立させると案B と区別がつかない |
| 居合（画面を斬って割る） | **捨てた** | split は強いが、移動・全画面・ウィンドウ切替・コピーに対応する動作がなく、1 操作しか乗らない |
| ルービックキューブ | **文化だけ全案に統合**（PB・Ao5・スクランブル・+2・記法風のキー表示） | 回す・揃えるが split / zoom / copy に対応しない。商標でもある。記録文化は既存の「直近 5 回平均」と「毎回ちがう順」に名前を付けるだけで入る |
| 編集局（新聞） | **案C として残した** | 飲食ではなく、段組・面・切り貼り・締切と tmux の対応が自然。紙・墨・朱の見た目が他 2 案と最も離れていて、選択肢として意味がある |

## 推し案: 案B tmux からくり屋敷（次点: 案A ON AIR）

初版では ON AIR を推したが、要件が変わったので入れ替える。

1. **tmux の本質を一言で言える。** 「屋敷を出ても、仕掛けはそのまま」= デタッチしてもセッションが残る。これを題名の下の一行目に置けるのは案B だけ。案A・案C は分割と切替は語れるが、デタッチが語れない。
2. **仕掛けの語彙がすべての操作を覆う。** 襖（split / resize / zoom）、間を渡る（focus）、部屋が回る（swap / layout）、棟（window）、巻物（copy mode）。敵を出さなくても「閉じる」対象（空き間）が自然にある。
3. **「遅れ」の扱いが世界観に溶ける。** 行灯がともる → 指南が出る、は「屋敷が待ってくれる」と読め、時間切れで飛ばさない方針と矛盾しない。ON AIR の「生放送は止まらないのにカットは飛ばない」は少し説明が要る。
4. ユーザーの反応（障子を開けていく、からくり屋敷なるほど）と最も近い。間取り図・迷い家の発想も吸収できた。
5. 見た目が今の 8bit ドラクエから十分に遠く、かつ「和」の落ち着きがある。明朝＋和紙＋行灯の橙で、端末部分も和紙色にして違和感がない。

弱点: 端末を和紙色にするので、黒い端末の「tmux らしさ」は案A より薄い。ダークテーマでは屋敷の中を夜（濃紺の端末に行灯の光）にする、という逃げ道がある。

案A ON AIR は「tmux の画面そのもの」という強みと「視聴率 N%」の数字の気持ちよさがあり、黒い端末を保ちたいなら案A。案C 編集局は言葉の切れ味（校了・誤植・縮刷版）で選ぶ案。
