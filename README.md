# tmux打（tmux-da）

寿司打のように、出されたお題を tmux のキーでさばいてタイムを競うゲーム。押すキーはいつも画面に出るので、遊んでいるうちに指が覚える。

- **ブラウザ版（`web/`）**: タイムアタックと、1 面ずつ覚える 3 章 24 面の冒険。インストール不要、通信なし
- **CLI 版（`./tmux-da`）**: 本物の tmux の中で 11 面を解く

## ブラウザ版（`web/`）

ページの中の小さな tmux で遊ぶ版。速さを競うタイムアタック（闘技場）と、CLI 版の 11 面に続きがある全 3 章 24 面の冒険がある。通信は一切しないので、`web/index.html` をそのまま開けば動く（`file://` でも静的サーバーでも）。

| 章 | 面 | 覚えること |
|---|---|---|
| 第 1 章 はじまりの村（初級） | 1〜11 | CLI 版の 11 面と同じ |
| 第 2 章 試練の塔（中級） | 12〜19 | 窓の入れ替え、レイアウト、コピーモードの検索・コピー・貼り付け、ウィンドウを閉じる、セッションを作る・切り替える |
| 第 3 章 魔王の城（上級） | 20〜24 | 押せるキーの数（MP）に上限がある連続技。最後は時間制限つきの魔王戦 |

- **タイムアタック（闘技場）**: 初級・中級・上級の 3 コース。お題の組は毎回同じで、順番は寿司打のように毎回ちがう。押すキーと操作の説明はいつも画面に出る。クリアまでの時間を競い、お題と関係ない操作は +2 秒、1 問の時間切れは +5 秒
- BGM と効果音は Web Audio で鳴らす（音のファイルは読み込まない）。右上の ♪ で消せる

```bash
open web/index.html                      # macOS
python3 -m http.server -d web 8000       # または http://localhost:8000/
```

- タイトル画面で prefix（Ctrl+b / Ctrl+a）を選ぶ。進み具合と設定は localStorage に残る（無くても動く）
- Mac で Ctrl+矢印が Mission Control に取られるときは、prefix のあと Option+矢印でも大きさを変えられる
- 狭い画面では画面下にキーの列が出るので、iPhone でも遊べる
- ライト／ダークは OS 設定に従い、右上のボタンで切り替えられる

テストは Playwright（Chromium）で、本物のキーボードイベントだけで 24 面と魔王戦を両方の prefix と電話幅で通し、闘技場の 3 コース、MP 切れ、途中からの再開、Ctrl+a prefix、Option+矢印、電話幅のレイアウトも確かめる。Playwright はプロジェクトの外に入れて、そのディレクトリから実行する:

```bash
mkdir -p /tmp/pw && cd /tmp/pw && npm i playwright
node /path/to/tmux-da/web/test/playthrough.mjs
SHOTS_DIR=/tmp/shots node /path/to/tmux-da/web/test/playthrough.mjs   # スクリーンショットも撮る
```

## CLI 版

本物の tmux の中で、11 の試練を解きながら基本操作を覚える。

- 宝箱やモンスターの窓（ペイン）が現れ、キー操作で解決すると次の面に進む
- 判定は自動。裏で見張り役が tmux の状態を読んでいる
- 専用のソケット（`tmux -L tmux-da`）と専用の設定で動くので、普段の tmux や `~/.tmux.conf` には影響しない

### 遊び方

```bash
./tmux-da
```

- 迷ったら `prefix` → `i` で、いまの面の説明が出る
- 途中でやめても、もう一度 `./tmux-da` で続きから
- herdr や tmux の中で起動すると、`Ctrl+b` の取り合いを避けて prefix を `Ctrl+a` にする。素のターミナルなら `Ctrl+b`

| コマンド | 内容 |
|---|---|
| `./tmux-da cheat` | キーの早見表 |
| `./tmux-da status` | いまの面 |
| `./tmux-da reset` | セッションと進み具合を消す |

### 面の一覧

| 面 | 覚えること | キー |
|---|---|---|
| 1 | 左右に分割 | `%` |
| 2 | 上下に分割 | `"` |
| 3 | ペインの移動 | 矢印キー |
| 4 | 全画面 | `z` |
| 5 | ペインを閉じる | `x` |
| 6 | 大きさを変える | `Ctrl`+矢印 |
| 7 | 新しいウィンドウ | `c` |
| 8 | ウィンドウ名の変更 | `,` |
| 9 | ウィンドウの移動 | `n` `p` 番号 |
| 10 | コピーモードでスクロール | `[` |
| 11 | デタッチと再接続 | `d` |

## 必要なもの（CLI 版）

- tmux 3.2 以上（ポップアップを使う）。3.8 で確認
- bash 3.2 以上（macOS 標準の bash で動く）

## テスト（CLI 版）

```bash
test/playthrough.sh
```

キー操作の代わりに tmux のコマンドで全面を解き、見張り役が 1 面ずつ進めるかを確かめる。`script(1)` で疑似端末のクライアントをつなぐので、デタッチと再接続の面も試せる。
