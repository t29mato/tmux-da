# tmux からくり屋敷（tmux-da）

tmux のキーで屋敷の仕掛けを解くタイムアタック。襖を立て（分割）、間を渡り（移動）、大広間にし（全画面）、棟を建て（ウィンドウ）、巻物を読む（コピーモード）。押すキーはいつも画面の「指図」に出ているので、遊んでいるうちに指が覚える。

**▶ 今すぐ遊ぶ: https://t29mato.github.io/games/tmux-da/**

- **ブラウザ版（`web/`）**: 3 つの屋敷のタイムアタック。インストール不要、通信なし
- **CLI 版（`./tmux-da`）**: 本物の tmux の中で 11 面を解く

## ブラウザ版（`web/`）

ページの中の小さな tmux で遊ぶ。通信は一切しないので、`web/index.html` をそのまま開けば動く（`file://` でも静的サーバーでも）。

| 屋敷 | 仕掛け | 目安 | 中身 |
|---|---|---|---|
| 三間屋敷（手ならし） | 15 | 12 秒 | 分割・移動・全画面・閉じる・ウィンドウの作成と切り替え。1 仕掛け 1 キー |
| 八間屋敷（おすすめ） | 20 | 14 秒 | 大きさ・名前・入れ替え・ウィンドウを閉じる・コピーモードも混ざる |
| 百間屋敷（真剣勝負） | 16 | 18 秒 | 1 仕掛けで 2〜3 手の連続技 |

- 仕掛けの組は毎回同じで、順番だけが毎回ちがう。全部解くまでの時間を競う。違う操作は +2 秒（仕掛け違い）
- **時間切れで飛ばさない**: 1 問は解けるまで終わらない。指図には答えの手順（指南）と押すキーがいつも出ている。目安を過ぎると行灯がともるが、先には進まない。タブを離れると自動で一時停止
- 結果は「絵巻」に残る。自己ベスト、五回平均、目標タイム（当主の刻）との差、称号（見習い → 仕掛け番 → 屋敷守 → からくり師 → 名匠）、遅れた仕掛け
- 「絵巻」の画面で、屋敷ごとのタイムの移り変わりと、灯りが多い（苦手な）仕掛けとそのキーが見られる
- 音は Web Audio で鳴らす（琴・拍子木・鈴。音のファイルは読み込まない）。右上の ♪ で消せる

```bash
open web/index.html                      # macOS
python3 -m http.server -d web 8000       # または http://localhost:8000/
```

- 合図（prefix）は tmux 標準の Ctrl+b。記録と設定は localStorage に残る（無くても動く）
- Mac で Ctrl+矢印が Mission Control に取られるときは、prefix のあと Option+矢印でも大きさを変えられる
- 狭い画面では画面下にキーの列が出るので、iPhone でも遊べる
- 夜の屋敷（ダーク）／昼の屋敷（ライト）は OS 設定に従い、右上のボタンで切り替えられる

テストは Playwright（Chromium）で、本物のキーボードイベントだけで 3 つの屋敷を両方の prefix と電話幅で通す。ほかに次も確かめる。
- 全種類の仕掛けを、ゲーム内の指南に従うだけで解けること
- 目安を過ぎても飛ばないこと（時計を進めて確認）
- 行の編集
- 記録の移行と上限
- 音の音域と音割れ

Playwright はプロジェクトの外に入れて、そのディレクトリから実行する:

```bash
mkdir -p /tmp/pw && cd /tmp/pw && npm i playwright
node /path/to/tmux-da/web/test/playthrough.mjs
SHOTS_DIR=/tmp/shots node /path/to/tmux-da/web/test/playthrough.mjs   # スクリーンショットも撮る
```

## CLI 版

本物の tmux の中で、11 の試練を解きながら基本操作を覚える。

- 宝箱やモンスターの窓（ペイン）が現れ、キー操作で解決すると次の面に進む
- 判定は自動。裏で見張り役が tmux の状態を読んでいる
- 専用のソケット（`tmux -L tmux-da`）と専用の設定で動くので、普段の tmux や `~/.tmux.conf` には影響しない

### 遊び方

```bash
./tmux-da
```

- 迷ったら `prefix` → `i` で、いまの面の説明が出る
- 途中でやめても、もう一度 `./tmux-da` で続きから
- herdr や tmux の中で起動すると、`Ctrl+b` の取り合いを避けて prefix を `Ctrl+a` にする。素のターミナルなら `Ctrl+b`

| コマンド | 内容 |
|---|---|
| `./tmux-da cheat` | キーの早見表 |
| `./tmux-da status` | いまの面 |
| `./tmux-da reset` | セッションと進み具合を消す |

### 面の一覧

| 面 | 覚えること | キー |
|---|---|---|
| 1 | 左右に分割 | `%` |
| 2 | 上下に分割 | `"` |
| 3 | ペインの移動 | 矢印キー |
| 4 | 全画面 | `z` |
| 5 | ペインを閉じる | `x` |
| 6 | 大きさを変える | `Ctrl`+矢印 |
| 7 | 新しいウィンドウ | `c` |
| 8 | ウィンドウ名の変更 | `,` |
| 9 | ウィンドウの移動 | `n` `p` 番号 |
| 10 | コピーモードでスクロール | `[` |
| 11 | デタッチと再接続 | `d` |

## 必要なもの（CLI 版）

- tmux 3.2 以上（ポップアップを使う）。3.8 で確認
- bash 3.2 以上（macOS 標準の bash で動く）

## テスト（CLI 版）

```bash
test/playthrough.sh
```

キー操作の代わりに tmux のコマンドで全面を解き、見張り役が 1 面ずつ進めるかを確かめる。`script(1)` で疑似端末のクライアントをつなぐので、デタッチと再接続の面も試せる。

```bash
scripts/publish.sh            # ../t29mato.github.io/games/tmux-da/ にコピー（SITE_DIR で変更可）
```
